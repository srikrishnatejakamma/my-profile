  • Insurance application development: Implemented Java/J2EE, Struts, Hibernate and JSP components for policy administration, commissions, operational reports and related insurance workflows within an MVC architecture.
  • Persistence & transactions: Developed reusable server-side components and Hibernate data-access logic; applied transaction handling, input validation, controlled access and exception management.
  • External integrations: Integrated payment gateways, automobile-data services, RightFax and messaging platforms; investigated integration failures and transaction-processing defects.
  • Policy uploads: Used Apache POI for Excel-based policy generation, processing and bulk uploads, connecting uploaded policy data with application workflows.
  • Mapping capabilities: Integrated Google Maps API V3 for EzyMap policy visualization and air-distance calculations and supported location-based policy registration features.
  • User interfaces: Developed JSP, HTML, CSS, JavaScript, jQuery and AJAX forms and reporting screens with dynamic validation for English and Arabic workflows.
  • Testing & UAT: Wrote JUnit tests and supported functional, integration and regression validation; investigated UAT defects, implemented fixes and assisted release verification.
  • Environment & troubleshooting: Configured test/UAT environments and supported Windows/Linux deployment configuration; resolved UI, business, persistence and integration issues and improved queries and code paths.
  • Team delivery: Worked with senior developers, business analysts and QA to turn insurance requirements into application functionality; participated in peer reviews, documentation and knowledge transfer.

Environment

Languages: Java/J2EE, JavaScript

Frameworks: Struts, Hibernate, JSP

Frontend: HTML, CSS, JavaScript, jQuery, AJAX

Integration: XML, Google Maps API V3, Apache POI

Testing: JUnit

Reporting: iReports

Platforms: Windows, Linux
